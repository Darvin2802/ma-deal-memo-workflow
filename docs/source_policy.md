# Source Policy

## Source quality hierarchy

The workflow should prioritize sources in this order:

1. Primary
2. Company website
3. Secondary

## Primary sources

Primary sources include:
- company press releases
- stock exchange filings
- regulator filings
- SEC filings
- SEDAR+ filings
- TSX / TSXV filings
- transaction agreements
- proxy or information circular documents
- officially hosted investor presentations
- official closing announcements

These should be used first wherever available.

## Company website sources

These include:
- portfolio pages
- subsidiary pages
- asset pages
- project pages
- business segment descriptions
- annual report pages or hosted PDFs

These are useful for asset detail and business profile, but should not override transaction documents.

## Secondary sources

These include:
- reputable financial press
- M&A media
- advisor announcements
- law firm deal pages
- transaction databases
- newswire reposts

Secondary sources may be used when:
- primary materials are missing
- primary materials are incomplete
- advisor identification is not disclosed in official sources

## Rules for use

- Every factual statement should be tied to a source.
- Primary-source facts and secondary-source facts should not be blended together without labeling.
- If a document is identified but not accessible, it should be labeled as identified but not accessed.
- If a fact cannot be confirmed, the memo should say so directly.
- Missing information should not be filled by inference.

## Ownership discipline

Ownership structures should be reported only where confirmed by:
- official filings
- company disclosures
- regulator records
- reliable corporate registry information where publicly available

Do not infer ultimate ownership from branding, naming, or market convention.

## Deal term discipline

Do not state deal value, consideration mix, stake, approvals, or mechanics unless a retrieved source confirms them.

If not confirmed, say so clearly.

## Legal clause discipline

Where legal clauses are relevant:
- quote briefly only when useful
- explain in simple business language
- avoid long verbatim extracts
